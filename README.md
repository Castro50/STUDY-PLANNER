# Study Planner

Cavendish University Uganda - Internet & Web Programming Exam 2026

## Problem Statement
University students struggle to organize their study schedules. Tasks are forgotten, deadlines are missed, and no simple offline tool exists for task tracking. This project solves this problem by providing a browser-based study planner that works offline, saves tasks automatically, and requires no login.

## Features
- Add new tasks with name, subject, and due date
- Delete unwanted tasks
- Mark tasks as complete or incomplete
- Filter tasks by All, Pending, or Completed
- Automatic save to localStorage (tasks persist after page refresh)
- Responsive design (works on phones, tablets, and desktops)

## Technologies Used
HTML5 for semantic page structure
CSS3 for styling, gradients, and responsive layout
JavaScript for task CRUD operations, filtering, and localStorage
localStorage for client-side data persistence

## How to Run
1. Download or clone this repository
2. Open index.html in any modern browser
3. No internet connection required after first load
4. Tasks save automatically even after closing the browser
